# Uber-Data-Analysis
Uber Data Analysis Dashboard

Project Overview

This project focuses on analyzing Uber booking data to understand booking performance, revenue, ride distances, vehicle types, customer ratings, and pickup locations. An interactive dashboard was developed using Power BI to transform raw data into meaningful insights and support data-driven decision-making.

Tools & Technologies

- SQL – Data analysis and querying
- Power Query – Data cleaning, transformation, and preparation
- Power BI – Interactive dashboard creation and data visualization

Key Performance Indicators (KPIs)

- Completed Bookings
- Lost Bookings
- Total Revenue
- Total Distance Travelled
- Average Distance
- Customer Ratings
- Driver Ratings

Dashboard Features

- Overview of booking performance
- Completed, cancelled, and incomplete ride analysis
- Revenue analysis
- Monthly booking trends
- Vehicle type analysis
- Pickup location analysis
- Customer and driver rating insights
- Interactive filters for exploring data

Key Insights

- Analyzed booking status to understand successful and unsuccessful bookings.
- Evaluated revenue and ride-distance performance.
- Compared booking trends across different months.
- Examined vehicle types and pickup locations.
- Analyzed average customer and driver ratings.

Project Objective

The main objective of this project is to analyze ride-booking data, identify important trends and performance indicators, and present insights through an interactive Power BI dashboard.
